# Contributing

This repository is a published mirror. Development happens in a private canonical monorepo.

- `booking-agent/` on `master` is generated. Pull requests that edit it by hand are closed, and the next generated sync overwrites any divergence. Report problems or suggest changes by opening an issue instead.
- `platform-profile.json` is generated by the same private source. It changes only through a generated pull request into `main` (the GitHub Pages branch), followed by a matching pull request into `master`.
- `main` contains only the profile, its vendored schemas, validators, and docs. Its `validate` check rejects any other path.

See [docs/OWNERSHIP.md](docs/OWNERSHIP.md) for branch roles and ownership.
